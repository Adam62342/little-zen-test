# Glance Sites

Choose websites where links open in Zen's Glance preview instead of a new tab.

## Settings (Settings → Sine Mods → Glance Sites)
- **Websites**: comma-separated, e.g. `reddit.com, news.ycombinator.com`. Subdomains match too, and `www.` is ignored.
- **Which links**: only links that would open a new tab (`target="_blank"`, middle-click, Ctrl/Cmd+click), or all links on those sites.

Alt+click (Zen's own Glance shortcut) and Shift+click (new window) are left alone.

## Install
1. Install Sine and enable installing JS from unofficial sources in Sine's settings.
2. Paste `YOUR_USERNAME/zen-glance-sites` into the Sine marketplace box.
3. Restart Zen.
