# Glance on Hold

Click and hold a link (left button, no modifier keys) and Zen's Glance preview opens after a short delay.
Move the cursor, release early, or start a drag and nothing happens. Normal clicks are untouched.

Pick the hold duration (0.4 s to 2.5 s) in Settings → Sine Mods → Glance on Hold.

## Install
1. Install Sine and enable installing JS from unofficial sources in Sine's settings.
2. Paste `YOUR_USERNAME/zen-glance-on-hold` into the Sine marketplace box.
3. Restart Zen.
